# 📚 University Projects

A collection of C programming projects and lab exercises completed during my university studies.

---

## 🗂️ Structure

The repo is organized by semester and lab session. Each lab folder contains a `.c / .py` source file with the solution and a `README.md` describing the exercise and approach.

---

## 🛠️ Language & Tools

- **Language:** C
- **Compiler:** GCC
- **OS:** Linux / Windows (via MinGW or WSL)

---

## 🚀 How to Compile & Run

Each `.c` file can be compiled individually with GCC:

```bash
gcc filename.c -o output
./output
```

Example:

```bash
cd LAB/LAB10/lab10.1
gcc lab10.1.c -o lab10.1
./lab10.1
```
